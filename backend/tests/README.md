# 통합 확인

심사 시연에서 보여줄 흐름이 끝까지 끊기지 않는지 확인한다.

```
로그인 → 이력서·JD 업로드 → 면접 진행 → 결과 리포트 → 피드백 보고서 → 마이페이지
```

프롬프트 품질·그래프 로직·전 화면 QA 는 대상이 아니다.

| | 확인 방법 |
|---|---|
| **백엔드** | `demo_flow_check.py` 자동 실행 |
| **화면(Streamlit)** | 아래 시나리오로 직접 조작 |

---

## 백엔드 — 자동 확인

```bash
# 터미널 1
uvicorn backend.main:app --port 8000

# 터미널 2
python backend/tests/demo_flow_check.py
python backend/tests/demo_flow_check.py --keep   # 테스트 데이터 남기기
```

> ⚠️ **실제 LLM 을 호출한다.** 면접 1회에 gpt-5-mini 호출이 십수 번 발생하므로 필요할 때만 실행할 것.

확인 항목 — 회원가입·로그인 / 이력서·JD 등록 / 면접 시작·진행·종료 / 꼬리질문 생성 / 실시간 점수 응답 / 결과 리포트(점수·역량·총평·총점 계산식) / 피드백 보고서 / 기록 목록 / DB 컬럼 저장

## 화면 — 직접 확인

### 사전 준비

| | 항목 | ☐ |
|---|---|---|
| 1 | `develop` 최신 pull | ☐ |
| 2 | `pip install -r requirements.txt` | ☐ |
| 3 | `DROP TABLE IF EXISTS interview_resume_optimizations;`<br>`DROP TABLE IF EXISTS interview_question_feedbacks;`<br>`DROP TABLE IF EXISTS interview_results;` | ☐ |
| 4 | `.env` 에 `OPENAI_API_KEY`, `DATABASE_URL`, `SECRET_KEY` | ☐ |
| 5 | 백엔드 `uvicorn backend.main:app --port 8000` | ☐ |
| 6 | 프론트 `streamlit run frontend/app.py` | ☐ |
| 7 | 테스트용 이력서·JD 파일 (pdf/docx/hwpx) | ☐ |

### 1. 로그인

**조작** 랜딩 → 로그인 → 테스트 계정
**기대** 로그인 성공, 면접 환경설정으로 이동

- 로그인 후 새로고침(F5) 해도 로그인이 유지되는가? ☐

### 2. 이력서·JD 업로드

**조작** 이력서 업로드 → JD 업로드 → 페르소나 선택 → 시작
**기대** 두 파일 업로드 성공, 면접 화면으로 이동

- 지원하지 않는 형식(`.txt`) 업로드 시 안내가 뜨는가? ☐
- 첫 질문이 선택한 페르소나 말투인가? ☐

### 3. 면접 진행

**조작** 답변 입력 → 전송, 최소 3~4턴
**기대** 답변마다 다음 질문이 나옴

- 일부러 짧고 부실하게 답하면 **꼬리질문**이 나오는가? ☐
- 꼬리질문에 표시가 붙는가? ☐
- 응답 대기 중 화면이 멈추거나 오류가 나지 않는가? ☐
- 마이크(음성 입력)가 동작하는가? ☐

### 4. 결과 리포트

**조작** 면접 완주 또는 종료
**기대** 결과 로딩을 거쳐 결과 리포트로 이동

- 총점·이력서 점수·면접 점수가 표시되는가? ☐
- 레이더 차트가 **실제 값**인가? (`59, 62, 61, 57, 62` 고정값이면 목업) ☐
- 종합 총평(강점·개선점·추천)이 나오는가? ☐
- 등급(A+, B+ 등)이 표시되는가? ☐

### 5. 피드백 보고서

**조작** "피드백 보고서 보기"
**기대** 질문별 내 답변·점수·모범 답안 표시

- 질문 개수가 실제 진행한 턴 수와 맞는가? ☐
- 평균 점수가 표시되는가? ☐

### 6. 마이페이지

**조작** 사이드바 → 마이페이지
**기대** 방금 진행한 면접이 목록 맨 위에 표시

- 날짜·면접관 유형·점수가 방금 본 결과와 일치하는가? ☐
- 상단 통계 카드(총 횟수·평균 점수)가 실제 값인가? ☐

### 7. 재시작 · 로그아웃

- "다시 면접하기" → 환경설정으로 이동, 이전 내용이 남지 않는가? ☐
- 로그아웃 후 뒤로가기로 내부 화면에 접근되지 않는가? ☐

## 확인 대상이 아닌 것 (현재 미구현)

**아래는 동작하지 않는 게 정상이다.** 결함으로 기록하지 않는다.

| 항목 | 상태 |
|---|---|
| 면접 화면 우측 **실시간 분석 패널** | 고정값 (백엔드는 턴마다 값 제공 중) |
| 결과 리포트 **역량별 코멘트** | 백엔드까지 완료, 화면 표시 대기 |
| 결과 리포트 **발화 속도** | 백엔드까지 완료, 화면 표시 대기 |
| 이력서 최적화 **키워드** | 그래프 노드에서 빈 값으로 넘어옴 (백엔드·화면은 연결됨) |
| 결과 리포트 **비교 평균** | 페르소나 기준으로 확정, 미구현 |
| 결과 리포트 **AI 영상 분석 코멘트** | 고정 문구 |
| 마이페이지 **최근 30일 점수 향상** | 정의 미정 |
| **OAuth 로그인**(구글·카카오) | 501 |

## 종료 판정

- 1~7 단계가 **끊기지 않고 끝까지 진행**되면 데모 경로는 확보된 것으로 본다.
- 중간에 막히는 항목이 있으면 **그것만** 우선 처리 대상이다.
- 표시가 어색하거나 값이 이상한 정도는 기록만 하고 진행한다.
