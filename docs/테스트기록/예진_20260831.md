## 1. 라포(자기소개) 질문 도입 (8/26)

면접 첫 질문으로 라포 질문을 넣고, 채점·꼬리질문·리포트에서 제외되는지 확인했다.

| 확인 | 결과 |
|---|---|
| 라포 질문 뒤에 꼬리질문이 붙던 문제 | type 불일치가 원인 (프롬프트 "라포" vs 그래프 판별값) → 현주님이 그래프 값 정합 후 정상 |
| 라포 다음 본 질문 전환 | 안내 문구 거쳐 정상 전환 확인 |
| 라포 질문 문장 | "…자기소개 부탁드립니다?" 처럼 서술문+물음표로 어색 → 예시를 물음형으로 수정 |

수정 후 새로 생성한 라포 질문 5개 전부 `물음표 종결 · 괄호 없음`으로 나왔다.

```
먼저 긴장 풀 겸 간단히 자기소개 해주시겠어요?
먼저 긴장 풀 겸 간단히 자기소개와 이 직무에 지원하신 이유를 말씀해 주시겠어요?
```

## 2. 프롬프트 규칙 준수율 (8/26)

현재 프롬프트로 질문을 새로 생성해, 규칙 준수 체커로 3라운드(75문항) 평균을 냈다.

| 규칙 | 준수율(평균) | 범위 |
|---|---|---|
| 괄호 없음 | 100% | 100% |
| 암송·수치강요 없음 | 97.3% | 96~100% |
| 물음표 종결 | 93.3% | 84~100% |
| 한 번에 하나만(요청 1개) | 61.3% | 44~72% |

**괄호·암송·물음표는 안정적**이고, `한 번에 하나만`이 가장 편차가 크고 낮다.

### rule 7 강화 전/후

"두 개 이상 개념을 그리고/및/각각으로 잇지 말 것" + 나쁜 예시를 추가했다.

```
요청 1개 준수율   56% → 61%  (다른 규칙은 그대로 유지)
```

개선은 됐으나 여지가 가장 큰 항목이라 추가 보강이 필요하다.

## 5. RAG 도입 전 / 후 질문 비교 (8/26)

같은 JD(서버 개발자)·이력서로 RAG 없이 / 있이 질문을 생성해 비교했다.

**RAG 없음** — 한 질문에 여러 개념을 나열해 길어진다.

```
대량 거래를 정산하는 시스템을 설계한다면 트랜잭션 경계와 소수점 처리 정책,
실패와 재시도 전략, 중복 방지와 리콘실리에이션 절차를 어떻게 설계하시겠습니까?
```

**RAG 있음** — 한 개념씩 초점이 있고, 실무 경험을 검증한다.

```
대량 거래를 정산하는 시스템을 설계해야 한다면 중복 처리와 재시도 과정에서
정합성을 어떻게 보장하시겠습니까?

블루그린이나 카나리 배포를 직접 설계하거나 운영해보신 적이 있나요?
```

카드의 "지식이 아니라 실제로 겪었는지 가른다" 관점이 질문에 반영된다.

## 6. 영상 분석 (8/26)

시선(카메라)·발화 속도(마이크) 보조 지표. 두 가지 문제를 확인하고 고쳤다.

### 발화 속도가 안 나오던 문제

```
원인   speech_rate 가 video_assist.py 에 있는데, 이 파일이 최상단에서
       mediapipe 를 import 하며 실패 시 sys.exit(1) → speech_rate 까지 못 불러옴
해결   cv2·mediapipe 를 lazy import 로 바꿔, mediapipe 없는 백엔드에서도
       speech_rate 동작. 시선 분석은 호출 시 가드로 격리
```

백엔드에서 `speech_cpm` 정상 계산 확인.

### 얼굴을 가려도 시선 점수가 안 떨어지던 문제

```
원인   얼굴 미검출 프레임을 집계에서 제외 → 가린 시간이 무시됨
해결   미검출 프레임을 "미응시"로 분모에 포함 → 가리거나 이탈한 만큼 하락
```

### 격리 실행 + 과거 영상 복구

mediapipe(protobuf 4.25)와 RAG(chromadb, protobuf 7)가 한 파이썬에 못 살아서,
mediapipe 를 별도 venv 로 subprocess 실행하는 브릿지로 전환했다.
과거에 실패(status=failed)로 남아 있던 영상들도 재분석해 복구했다.

```
재분석 결과   gaze 95.0 / 96.6 / 98.7% · status done
```
